# PokéSurvivor · copia personal de pruebas

Copia experimental y no oficial para probar ataques y ajustes. El juego original es de Jonathan Piera Torregrosa ([JPTER78/pokesurvivor](https://github.com/JPTER78/pokesurvivor)). La web oficial es [pokesurvivor.com](https://pokesurvivor.com).

Esta versión desactiva Firebase. El enlace principal abre un perfil temporal «Pruebas» con todos los Pokémon, monedas y mejoras. El progreso de ese perfil se pierde al cerrar la pestaña o recargar. No se conecta a las cuentas oficiales. Las cuentas locales normales, si se crean, sólo viven en este navegador.
